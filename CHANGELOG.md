# Changelog

All notable changes to Licarl Prompt Maker will be documented in this file.

## [1.0.0] - 2026-07-28

### Added
- Initial public release
- Full authentication system (register, login, OAuth, 2FA, password reset)
- Prompt builder with Monaco editor, variables, folders, tags, version history
- Multi-provider prompt tester (OpenAI, Anthropic, Google, xAI, DeepSeek, Mistral, Groq, OpenRouter, Together, Cohere, Azure, Ollama)
- Streaming AI chat with markdown and code highlighting
- AI Agents with system prompts, memory, and tools
- Visual workflow builder (prompt, condition, loop, API, delay, output nodes)
- Marketplace for publishing and discovering prompts
- Team collaboration (organizations, roles, shared resources, audit logs)
- Knowledge base with document upload and search
- File manager with storage analytics
- Real-time notifications via WebSocket
- Analytics dashboard (usage, costs, charts)
- Admin panel
- REST API + WebSocket + Swagger docs
- Docker, GitHub Actions, Vercel/Railway/Render deployment configs
- Dark/Light mode, responsive design, glassmorphism UI
